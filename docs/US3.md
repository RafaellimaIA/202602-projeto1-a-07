> Entregável da aula 20. Cada história nasce de uma oportunidade do mapa de jornada e vira uma Issue com o label `historia`.

| ID | História | Oportunidade de origem | Prioridade | Issue |
| --- | --- | --- | --- | --- |
| HU01 | Como cliente da Bulbe que não é titular da conta de luz, quero salvar meu progresso e continuar o cadastro posteriormente, para que eu possa concluir minha adesão sem precisar preencher novamente os dados já informados. | Simplificação do cadastro para clientes que não são titulares da conta de luz | Alta | #[ ] |

## Critérios de aceite

### HU01

- [ ] O sistema deve permitir salvar o cadastro mesmo que existam informações ou documentos obrigatórios pendentes.
- [ ] O usuário deve conseguir retomar o cadastro de onde parou, mantendo os dados preenchidos anteriormente.
- [ ] O sistema deve permitir que o CPF do titular e a conta de luz sejam fornecidos posteriormente.
- [ ] O sistema deve informar claramente quais dados e documentos ainda estão pendentes.
- [ ] Ao salvar o cadastro incompleto, o sistema deve exibir uma mensagem confirmando o salvamento.
- [ ] A conclusão da adesão só deve ser permitida quando todos os dados e documentos obrigatórios estiverem preenchidos e validados.
